## Runtime Limitation

ineligible (`iOS 26.5 is not installed`). No simulator runtime is installed. The verifier
therefore does not claim a device build; `--require-runtime` fails closed in release CI.
Installing a matching Xcode iOS platform is required for the final release-device gate.
