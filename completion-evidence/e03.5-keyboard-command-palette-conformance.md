# E03.5 Keyboard and command-palette conformance completion evidence

## Result

The primary desktop destinations now have one documented keyboard order: Cmd+1 through
Cmd+7 open Activity, Projects, Connections, Sessions, Files / Artifacts, Devices, and
Settings. The mapping is implemented independently of the persisted `NavSection` keys,
so existing saved navigation state remains compatible. Files / Artifacts uses the same
entry helper as its navigation-rail action, and every route establishes deterministic
library focus.

The global palette is keyboard-operable from both library and terminal workspace
contexts. Enter activation is covered for Projects, presets, active Sessions, archived
Sessions, recent commands, and the safe Show archive action. Escape returns focus to the
control that owned it before the palette opened. Terminal Enter remains terminal input
and cannot activate a palette, approval, launch, or resume action.

Implementation commit: `2aef2dc` (`feat(navigation): align keyboard and palette flows`).

## Acceptance mapping

- Cmd+1 through Cmd+7 follow the visible primary rail order without renumbering
  `NavSection::key` or any serialized discriminant.
- Cmd+5 and the Files / Artifacts rail item share `open_files_library` and open the
  Artifacts tab; Cmd+, and all numeric destinations leave a focused library surface.
- Typed palette-result tests preserve category and status semantics for Project, preset,
  active Session, archived Session, and safe action results.
- Project and preset activation reuse the reviewed launch flow; the preset remains in
  review and creates neither a workspace nor a Session record before confirmation.
- Repeated active-Session activation keeps one original Session identity, one pane, and
  one authoritative record. Archived activation creates neither a pane nor a record.
- Palette dismissal restores library or terminal focus; recent-command Enter restores
  terminal focus after dispatch.
- Terminal Enter is explicitly exercised while the terminal owns focus and does not open
  the palette, New Session, or Session Resume surfaces.
- No second search index, matcher, shortcut system, launcher, store, process owner,
  protocol, or mobile behavior was introduced.
