# E03.1 Primary navigation completion evidence

## Result

The desktop library now presents Activity, Projects, Connections, Sessions, Devices,
and Settings in workflow order. Existing specialized destinations remain available in
a separate advanced group, and the sidebar scrolls when vertical space is constrained.

Sessions reuses the existing project selector and project-owned session library, including
its explicit no-project state and recovery path. Devices reuses the existing route,
pairing, identity, trust, capability, revoke, and reset controls without creating a second
device state model. The internal `Hosts` enum and persisted host models were deliberately
left unchanged while customer-facing navigation and connection-list copy use Connections.

Implementation commit: `5db98cf` (`feat(navigation): surface primary desktop destinations`).
