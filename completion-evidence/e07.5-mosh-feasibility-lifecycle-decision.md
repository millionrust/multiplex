## Result

Mosh is deliberately deferred and no product capability is exposed. The accepted decision maps
the official SSH bootstrap, UDP state-synchronization session, bearer-key lifecycle, roaming,
timeout, packaging, and terminal semantics against TermiRust's verified SSH channel model.

The audit rejected an external wrapper because it would bypass saved authentication and
TermiRust host-key policy, rejected a custom protocol implementation, and documented the finite
runtime, security, product, packaging, and platform prerequisites for reconsideration. It also
removed the pre-existing decorative Mosh card, command input, state variant, and unsupported
failure labels from the connection UI.
