## Security Boundary

Private key bytes and passphrases remain local and are absent from ordinary state, diagnostics,
audit output, terminal output, and deployment traffic. Deployment never changes SSH daemon
policy, never chooses an arbitrary remote destination, never claims another login route exists,
and never labels a write as verified without a fresh generated-key connection. Hardware keys,
CA/signing workflows, root deployment, automatic rotation, and Windows secure-store claims
remain explicitly out of scope.

Known repository warnings from legacy `objc` macros, dead code, and future-incompatible
dependencies remain unchanged; the changed-line Clippy gate is clean.
