# E03.3 Files and Artifacts library completion evidence

## Result

Files / Artifacts is now a primary desktop destination with explicit Session artifacts
and SFTP files modes. The artifact mode refreshes the existing repository for every
authoritative typed Session, orders a cross-Project index deterministically, and displays
Project, Session, preset, state, type, size, and truthful explicit-import provenance.

Selecting an index row opens that Session's existing artifact gallery, so preview,
export, quarantine, restore, purge, quota, cancellation, and error behavior remain
authoritative. SFTP remains a separate live file browser and the chrome SFTP shortcut
continues to open SFTP behavior. Remote files are not converted into artifact records.

Implementation commit: `83d4a4f` (`feat(files): add unified files and artifacts library`).

## Acceptance mapping

- Primary navigation and the existing chrome SFTP shortcut enter the same Files /
  Artifacts destination with explicit mode selection.
- The pure index test covers multiple Projects, deterministic ordering, truthful origin,
  and exclusion of artifact scopes without an authoritative Session.
- The rendered test covers cross-Project artifact rows, explicit Project/preset/origin
  context, the selected Session's canonical gallery, and switching to the SFTP browser.
- Repository unavailability has an explicit error state instead of masquerading as an
  empty library.
- No artifact identity, Session identity, quota, storage format, process owner, protocol,
  or mobile behavior changed.
