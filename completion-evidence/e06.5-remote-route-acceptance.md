# E06.5 cross-platform remote route acceptance

Date: 2026-08-30
Status: complete

## Delivered

- Added one versioned acceptance fixture shared byte-for-byte by Rust, Swift, and Kotlin.
  It covers private LAN/VPN, Controller over SSH, and self-hosted relay routes.
- Exercised 24 route lifecycle programs: normal connection, online cancellation,
  retryable loss with unknown-mutation reconciliation, non-retryable authentication
  failure, revocation, repeated availability loss, connecting cancellation, and
  authorization restoration followed by explicit reconnect.
- Exercised every one of the six directional route switches. Unconfirmed and unavailable
  switches fail without changing the source; confirmed switches release source writer
  authority, clear source input, disconnect only the source, and never auto-start a target.
- Propagated the existing explicit-action requirement through the Rust, Swift, and Kotlin
  platform plans so UI/runtime owners cannot erase that safety requirement.
- Extended fixture synchronization and added a single repository gate that composes the
  shared lifecycle suite with the prior mobile contract, LAN, SSH, and relay fault suites.
- Locked zero automatic route switches and zero mutation replays into both fixture
  validation and all three client runners.

## Runtime And Product Limits

The Swift suite executed strict standalone route runners and typechecked the application
contracts, but no eligible iOS simulator or generic runtime destination is installed. The
Kotlin suite executed on the JVM, but no Android hardware or emulator was attached. Release
CI must still execute the existing require-runtime/device gates.

The production native Device transport set currently installs private LAN/VPN. Direct SSH
works as a Connection route, while native Controller-over-SSH and self-hosted-relay adapters
remain visibly unavailable until dedicated transports are installed. The acceptance fixture
proves their route ownership and failure contracts; it does not claim unavailable native
network transports were physically exercised.
