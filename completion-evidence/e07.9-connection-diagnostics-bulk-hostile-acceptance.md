- Status: complete

## Delivered

- Added one process-wide connection-diagnostic manager with four fixed workers, at most 64 queued
  operations, a 64-profile batch ceiling, per-profile deduplication, queued and active
  cancellation, retry, and typed lifecycle events.
- Added a strict read-only SSH probe that follows the saved direct, proxy, or jump route and uses
  saved authentication while requiring an existing exact known-host match. The ordinary
  interactive SSH path keeps its existing trust-on-first-use behavior.
- Probes open and close an SSH session channel without PTY, shell, or command execution, then open
  an SFTP subsystem and canonicalize the current directory to report capability truth.
- Diagnostic requests strip environment, startup directory, startup command, tmux settings, port
  forwards, and agent forwarding. Unknown trust never pins a key and diagnostics perform no remote
  mutation.
- Added distinct sanitized results for unknown trust, key mismatch, credential denial, route
  failure, timeout, channel denial, SFTP unavailability, cancellation, and internal failure.
- Added a visible Connections `Diagnose` bulk action and an unframed result panel with summary
  counts, route/stage/status/detail/elapsed fields, live cancellation, terminal retry, and clear.
- Added the decision record, focused verifier, and aggregate E07 infrastructure verifier.

## Acceptance Evidence

- Unit tests prove queue and worker bounds, duplicate rejection, batch normalization, queued and
  active cancellation, retry eligibility, route labels, error classification, and strict trust
  non-mutation.
- Live Docker tests prove unknown trust, reviewed pin then success, direct/proxy/jump routing,
  credential denial, host-key mismatch, SFTP denial and recovery, cancellation, and absence of
  startup-command, tmux, forwarding, or agent-forwarding side effects.
- A real stalled TCP peer proves the diagnostic timeout is bounded and active cancellation does
  not wait for the route timeout.
- Rendered GPUI acceptance presses the real Connections Diagnose control, observes an actionable
  unknown-trust result, and proves no workspace opens and no trust entry is created.

## Limits Preserved

Diagnostics are point-in-time checks for saved desktop SSH profiles. Continuous monitoring,
network discovery, automatic trust, automatic repair, credential display, terminal launch, remote
mutation, and cross-device diagnostic synchronization remain out of scope. Platform behavior is
claimed only for the macOS reference desktop and the Linux Docker SSH fixtures exercised here;
broader release claims remain gated.
