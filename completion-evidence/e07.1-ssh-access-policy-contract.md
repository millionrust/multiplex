# E07.1 SSH access capability and policy contract

Date: 2026-08-30
Status: complete

## Delivered

- Added a versioned pure-domain SSH access contract for password, private key, OpenSSH user
  certificate, local agent, and security-key authentication.
- Separated agent forwarding from authentication. Forwarding defaults off, has no persistent
  allow mode, requires local-agent and forwarding runtime capabilities, and requires fresh
  per-connection confirmation.
- Added certificate signer ownership for private-key, local-agent, and security-key signers.
  Missing certificate/signer material and unsupported providers fail before credential or
  socket access.
- Added typed available, provider-unavailable, and unsupported capability projection plus
  stable validation error codes.
- Added a shared v1 fixture with normal, missing-material, invalid-combination, unsupported,
  unavailable-provider, forwarding-denied, and forwarding-confirmed cases.
- Characterized legacy saved hosts: password and private-key JSON project to the matching new
  method with forwarding disabled, while their serialized shape remains unchanged.
- Recorded current SSH/SFTP/config-import ownership and the required common adapter boundary
  for E07.2/E07.3.
