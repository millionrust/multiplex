# E06.1 remote route selection contract

Date: 2026-08-29
Status: complete

## Delivered

- Added a UI- and transport-independent domain contract for local IPC, private LAN/VPN,
  user-provided SSH, and optional self-hosted relay routes.
- Frozen platform applicability, configuration requirements, trust layers, and the shared
  Controller capability surface. Relay policy requires system TLS, configured SPKI pin,
  relay admission, and independent Controller authentication.
- Added explicit disabled, unavailable, idle, connecting, authenticating, online,
  reconnecting, degraded, and revoked phases with closed transition validation.
- Added deterministic cleanup decisions for failures, cancellation, disable, and revoke:
  close only the active transport, clear pending input, and release held writer authority.
- Bounded retry semantics to the same route and idempotent reads. Unknown mutation
  completion requires command-ID reconciliation; acknowledged/rejected mutations never replay.
- Required confirmed route changes and rejected same-route, unavailable, and
  platform-inapplicable targets. Automatic route switching is always false.
- Added a versioned canonical fixture covering four route policies, twelve valid
  transitions, three invalid transitions, five mutation outcomes, and six switch cases.
