Status: complete

## Delivered

- Added canonical schema-v2 terminal operations covering SGR attributes and resets,
  ANSI/indexed/RGB colors, zero/narrow/wide Unicode scalar widths, wide-cell overwrite,
  no-reflow row/column resize, cursor clamping, and alternate-screen resize.
- Generated Swift and Kotlin width lookup tables from the exact `unicode-width 0.2.2`
  implementation used by desktop `vt100`; drift checks bind all native copies to Rust.
- Replaced string-only Swift and Kotlin terminal rows with bounded typed cells while
  retaining compatible plain-line snapshots for existing controller code.
- Added native attributed terminal-row rendering with 16/256/RGB colors, bold, dim,
  italic, underline, inverse, wide-continuation suppression, and selectable text.
- Kept parser accounting incremental per active row so sustained output does not scan
  retained scrollback for every scalar.
