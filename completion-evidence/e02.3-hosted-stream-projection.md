## Result

`SessionCoordinator` now classifies durable Host bound, output, and snapshot events into
closed terminal, Dev URL, selection, activity, refresh, and replay-boundary actions. The
application event loop maps events and applies those actions without deciding stream
semantics.

## Delivered

- Added closed bound/output/snapshot input and projection types.
- Preserved output bytes exactly, including non-UTF-8 data, NULs, escape sequences, and
  empty snapshots.
- Preserved output workspace activity, conditional selection clearing, pane refresh, and
  Dev URL observation ordering.
- Preserved snapshot terminal replacement with the pane's current size and configured
  scrollback, unconditional selection clearing, replay boundary advancement, and Dev URL
  snapshot application.
- Preserved bound events as Dev URL binding only, with no terminal or refresh action.
- Added a source-boundary test preventing terminal parsing, Dev URL mutation, or
  selection semantics from returning to the Host stream event branches.
