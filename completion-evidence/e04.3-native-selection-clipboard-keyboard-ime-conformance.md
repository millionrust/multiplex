# E04.3 native selection, clipboard, keyboard, and IME conformance

Date: 2026-08-29
Status: complete

## Delivered

- Added one canonical interaction-v1 corpus for terminal key bytes, application-cursor
  mode, Control and Alt chords, UTF-8 text, paste normalization and confirmation,
  bracketed paste, exact selection extraction, IME composition, and bounded safe URLs.
- Routed Swift touch controls, iOS external-keyboard commands, Android Compose controls,
  Android hardware keys, and both native IME bridges through pure tested encoders.
- Preserved the single-writer boundary and exact 256 KiB queue cap; multiline and large
  pastes require confirmation, cancellation sends nothing, confirmation is consumed
  once, and bracket delimiters are added only to the final payload.
- Added real-content cell rows beside the fixed viewport grid so native selection omits
  continuation cells and synthetic right-side padding while retaining styled text.
- Added explicit URL menus for visible lowercase `http` and `https` links only. URL
  count and byte length are bounded, and parser-suppressed OSC content cannot create a
  link action.
