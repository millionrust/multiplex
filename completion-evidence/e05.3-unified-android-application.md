# E05.3 unified Android application

Date: 2026-08-29
Status: complete

## Delivered

- Removed the Controller/direct-SSH product flavors and consolidated all production code,
  tests, fixtures, and JNI libraries into standard `main` and `test` source sets.
- Added one activity and adaptive Compose shell using a bottom navigation bar on phones and
  a navigation rail on tablets, bound to canonical Connections and Devices destinations.
- Kept direct SSH Keystore material and Controller pairing blobs under distinct aliases and
  storage paths; both routes now ship in the same application without sharing credentials.
- Added permanent Direct SSH and Device Session terminal labels.
- Added direct-SSH background privacy, unsent input/credential/paste/modifier cleanup,
  cancellable connection jobs, disconnect-on-background, and no input replay on resume.
- Replaced the obsolete Controller-only dependency exclusion check with a single-APK route,
  source-set, dependency, native-library, test, and build verifier.
